# S3 PLOWTURN

In the plow, you make the three turns without tipping. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3plowturn/

## Design

Three turns, still upright. A tip fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
