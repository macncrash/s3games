# S3 SLEDTURN

The sled has one job: make the three turns without tipping.

Play it in the browser: https://macncrash.github.io/s3games/play/s3sledturn/

## Design

Three hooks without tipping. Rolling the basket too far fails the run even if you made the turns.

The browser build is one file. The link above is that file, not a capture of a desktop session.
