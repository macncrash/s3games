# S3 GLIDERSLIP

Take the glider and berth in the slip before the tide turns. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3gliderslip/

## Design

Berth the flying boat before the tide turns. A late berth fails the leg even if you find the slip.

The browser build is one file. The link above is that file, not a capture of a desktop session.
