# S3 AMBER

One intersection. Stop the ones who run it. Spare the ones who don't.

Play it in the browser: https://macncrash.github.io/s3games/play/s3amber/

## Design

Runners are stopped and the ones who stop are spared. Hitting both, or neither, fails the intersection.

The browser build is one file. The link above is that file, not a capture of a desktop session.
