# S3 SKIFFTURN

The skiff has one job: make the three turns without tipping.

Play it in the browser: https://macncrash.github.io/s3games/play/s3skiffturn/

## Design

Three bends without tipping. A heel that puts the skiff over fails the creek even if you made the turns.

The browser build is one file. The link above is that file, not a capture of a desktop session.
