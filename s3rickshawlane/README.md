# S3 RICKSHAWLANE

In the rickshaw, you stay in the lane for the whole leg. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3rickshawlane/

## Design

Stay in the lane for the whole leg. One departure fails it.

The browser build is one file. The link above is that file, not a capture of a desktop session.
