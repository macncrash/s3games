# S3 ORCHARDCOLU

You have the orchard. The job is to stop the column on the road. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3orchardcolu/

## Design

Stop the column on the road. A truck that still gets through is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
