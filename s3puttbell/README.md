# S3 PUTTBELL

Putt: the bell rings before the third try dies. That is the whole cartridge.

Play it in the browser: https://macncrash.github.io/s3games/play/s3puttbell/

## Design

The bell has to ring before the third try dies. A later hole is already over.

The browser build is one file. The link above is that file, not a capture of a desktop session.
