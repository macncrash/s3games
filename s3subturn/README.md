# S3 SUBTURN

Take the sub and make the three turns without tipping. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3subturn/

## Design

Three turns upright before the other crew. One tip ends the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
