# S3 CAUSEWAYPACE

At the causeway, you wait until the third pace before you fire. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3causewaypace/

## Design

Wait for the third pace, then fire. An earlier shot is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
