# S3 SALLYCOLU

At the sally, you stop the column on the road. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3sallycolu/

## Design

Stop the column on the road. Letting a wagon through is not done.

The browser build is one file. The link above is that file, not a capture of a desktop session.
