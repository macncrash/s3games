# S3 SHUFFLE TAPE

A short shuffle. You are done when the drawer has to match the tape.

Play it in the browser: https://macncrash.github.io/s3games/play/s3shuffletape/

## Design

The drawer has to match the tape, and that closes the short shuffle. A disk that pays the same and is not on the tape stays out.

The browser build is one file. The link above is that file, not a capture of a desktop session.
