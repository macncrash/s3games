# S3 DEPOTDOOR

You have the depot. The job is to hold the door for three minutes. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3depotdoor/

## Design

The door has to hold for three minutes. Opening it early ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
