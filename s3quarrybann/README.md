# S3 QUARRYBANN

You have the quarry. The job is to bring the banner back. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3quarrybann/

## Design

Bring the banner back. Reaching the banner and leaving it there is not done.

The browser build is one file. The link above is that file, not a capture of a desktop session.
