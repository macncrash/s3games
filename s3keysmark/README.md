# S3 KEYSMARK

Keys: a finished mark ends it. That is the whole cartridge.

Play it in the browser: https://macncrash.github.io/s3games/play/s3keysmark/

## Design

Hold the phrase with no slips. That finished mark ends it. The rest of the piece is not the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
