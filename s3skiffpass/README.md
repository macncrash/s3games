# S3 SKIFFPASS

The skiff has one job: clear the pass before the storm clock.

Play it in the browser: https://macncrash.github.io/s3games/play/s3skiffpass/

## Design

Clear the pass before the storm clock dies. Making the pass with the clock already gone fails it.

The browser build is one file. The link above is that file, not a capture of a desktop session.
