# S3 RAILBUOY

In the rail, you round the buoys and return to the same dock. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3railbuoy/

## Design

Round the buoys and return to the same dock. Missing the dock fails the leg.
