# S3 METRO

Stop in the box. Overshoot is a fail.

Play it in the browser: https://macncrash.github.io/s3games/play/s3metro/

## Design

Overshoot is a fail, not a door you can reopen. The box is small on purpose so the stop is the whole skill.

The browser build is one file. The link above is that file, not a capture of a desktop session.
