# S3 PINSCHIME

Pins: the hour has to chime. That is the whole cartridge.

Play it in the browser: https://macncrash.github.io/s3games/play/s3pinschime/

## Design

The hour has to chime. Clearing the pins while the clock is still short of the hour is not this cartridge.

The browser build is one file. The link above is that file, not a capture of a desktop session.
