# S3 CLIFFLOCK

Take the cliff and pass the lock without scraping a gate. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3clifflock/

## Design

Pass the lock without scraping a gate. A scrape spends the run even if you clear the lock.

The browser build is one file. The link above is that file, not a capture of a desktop session.
