# S3 CHOIRCHIME

Play choir until the hour has to chime. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3choirchime/

## Design

The hour has to chime at 12:00:00. A phrase that misses the hour is still short.

The browser build is one file. The link above is that file, not a capture of a desktop session.
