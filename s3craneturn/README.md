# S3 CRANETURN

Take the crane and make the three turns without tipping. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3craneturn/

## Design

Three turns, still upright, with the other crew still on the clock. A tip fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
