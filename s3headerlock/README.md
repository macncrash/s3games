# S3 HEADERLOCK

In the header, you pass the lock without scraping a gate. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3headerlock/

## Design

Pass the lock without scraping a gate, and reach the end of the leg. A scrape spends the run.

The browser build is one file. The link above is that file, not a capture of a desktop session.
