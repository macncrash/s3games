# S3 SHELVEMARK

Play shelve until a finished mark ends it. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3shelvemark/

## Design

Finish the mark on the shelf. A row left open is still the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
