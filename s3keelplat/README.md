# S3 KEELPLAT

Take the keel and stop level with the platform. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3keelplat/

## Design

Stop level with the platform ahead of the other crew. Short or long fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
