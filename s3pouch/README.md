# S3 POUCH

The pouch crosses three streets. Drop it and the run is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3pouch/

## Design

The pouch has to cross three streets. Dropping it ends the run, so a fast crossing that loses the bag is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
