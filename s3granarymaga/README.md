# S3 GRANARYMAGA

At the granary, you make the magazine last longer than the raid. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3granarymaga/

## Design

The magazine has to outlast the raid. Running dry first ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
