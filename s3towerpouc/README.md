# S3 TOWERPOUC

At the tower, you carry the pouch across. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3towerpouc/

## Design

The pouch has to cross the tower. Stopping in the middle is not across.

The browser build is one file. The link above is that file, not a capture of a desktop session.
