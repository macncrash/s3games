# S3 REDOUBT PACE

At the redoubt, you wait until the third pace before you fire. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3redoubtpace/

## Design

Fire on the third pace. An earlier shot that still holds the redoubt is not the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
