# S3 GOLFMARK

Play golf until a finished mark ends it. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3golfmark/

## Design

A finished mark ends it. One hole in one stroke, then leave. The rest of a card is not the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
