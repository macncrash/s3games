# S3 HARBORDAWN

At the harbor, you keep the flares lit until dawn. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3harbordawn/

## Design

The flares have to stay lit until dawn. A dark flare before dawn is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
