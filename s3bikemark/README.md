# S3 BIKEMARK

Take the bike and set down on the mark. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3bikemark/

## Design

Set down on the mark before the other crew. Close and still off the mark fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
