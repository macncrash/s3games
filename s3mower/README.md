# S3 MOWER

Cut the field before the rain. The stripes are the score.

Play it in the browser: https://macncrash.github.io/s3games/play/s3mower/

## Design

The stripes are the score. The field has to be cut before the rain, and a missed stripe is still uncut.

The browser build is one file. The link above is that file, not a capture of a desktop session.
