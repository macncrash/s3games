# S3 GLIDERTURN

In the glider, you make the three turns without tipping. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3gliderturn/

## Design

Three turns without tipping. A bank that puts the glider over fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
