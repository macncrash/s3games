# S3 MEMORYCHIME

Play memory until the hour has to chime. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3memorychime/

## Design

The hour has to chime. Pairs that miss the hour do not end it.

The browser build is one file. The link above is that file, not a capture of a desktop session.
