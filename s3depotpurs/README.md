# S3 DEPOTPURS

One depot. Be the last machine still running. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3depotpurs/

## Design

Be the last machine still running. Stopping the others and then dying yourself does not take the depot.

The browser build is one file. The link above is that file, not a capture of a desktop session.
