# S3 CABSLIP

The cab has one job: berth in the slip before the tide turns.

Play it in the browser: https://macncrash.github.io/s3games/play/s3cabslip/

## Design

Berth in the slip before the tide turns. A late berth fails the job even if you find the slip.

The browser build is one file. The link above is that file, not a capture of a desktop session.
