# S3 CLIFFMARK

In the cliff, you set down on the mark. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3cliffmark/

## Design

Set the cart on the mark. Close and still off the mark fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
