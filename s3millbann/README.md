# S3 MILLBANN

At the mill, you bring the banner back. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3millbann/

## Design

Bring the banner back to the mill. Reaching the banner and leaving it there is not done.

The browser build is one file. The link above is that file, not a capture of a desktop session.
