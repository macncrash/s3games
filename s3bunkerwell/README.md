# S3 BUNKERWELL

One bunker. Keep the well standing through three waves. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3bunkerwell/

## Design

The well has to stand. A breach is a loss even if the score looks high.

The browser build is one file. The link above is that file, not a capture of a desktop session.
