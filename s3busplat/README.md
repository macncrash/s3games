# S3 BUSPLAT

Take the bus and stop level with the platform. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3busplat/

## Design

Stop level with the platform. Short or past the platform fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
