# S3 RICKSHAWLOCK

The rickshaw has one job: pass the lock without scraping a gate.

Play it in the browser: https://macncrash.github.io/s3games/play/s3rickshawlock/

## Design

Pass the lock without scraping a gate. One scrape fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
