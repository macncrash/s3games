# S3 TORPEDO

Two shots. The target has to sink.

Play it in the browser: https://macncrash.github.io/s3games/play/s3torpedo/

## Design

Two shots, and the target has to sink. A hit that does not sink it spends a shot. Both spent with the ship still up is a miss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
