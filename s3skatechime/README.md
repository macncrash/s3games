# S3 SKATECHIME

Skate: the hour has to chime. That is the whole cartridge.

Play it in the browser: https://macncrash.github.io/s3games/play/s3skatechime/

## Design

The hour has to chime, then leave. A run that ends before the hour is not this cartridge.

The browser build is one file. The link above is that file, not a capture of a desktop session.
