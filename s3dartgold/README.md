# S3 DARTGOLD

Play dart until only the gold counts double. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3dartgold/

## Design

Five-oh-one, and only a gold bed counts as a double. A cream double does not check out.

The browser build is one file. The link above is that file, not a capture of a desktop session.
