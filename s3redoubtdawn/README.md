# S3 REDOUBTDAWN

One redoubt. Keep the flares lit until dawn. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3redoubtdawn/

## Design

Keep the flares lit until dawn. A dark flare is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
