# S3 MAZEGOLD

Play maze until only the gold counts double. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3mazegold/

## Design

Only the gold counts double, then leave. Cream steps do not buy the double.

The browser build is one file. The link above is that file, not a capture of a desktop session.
