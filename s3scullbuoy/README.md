# S3 SCULLBUOY

Take the scull and round the buoys and return to the same dock. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3scullbuoy/

## Design

Round the buoys and beat the other crew home. A fast lap that finishes at the wrong dock fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
