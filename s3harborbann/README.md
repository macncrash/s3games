# S3 HARBORBANN

You have the harbor. The job is to bring the banner back. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3harborbann/

## Design

The banner has to come back to the harbor. Reaching it and staying away is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
