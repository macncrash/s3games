# S3 PUTT

Nine short holes. Only the cup counts.

Play it in the browser: https://macncrash.github.io/s3games/play/s3putt/

## Design

Only the cup counts. Sitting on the green is not a score, so every stroke is aimed at the hole rather than at a safe lay-up.

The browser build is one file. The link above is that file, not a capture of a desktop session.
