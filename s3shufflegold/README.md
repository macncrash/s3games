# S3 SHUFFLEGOLD

Shuffle: only the gold counts double. That is the whole cartridge.

Play it in the browser: https://macncrash.github.io/s3games/play/s3shufflegold/

## Design

A gold disk in the 3 counts double. Cream does not buy the double.

The browser build is one file. The link above is that file, not a capture of a desktop session.
