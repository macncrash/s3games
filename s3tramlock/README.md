# S3 TRAMLOCK

Take the tram and pass the lock without scraping a gate. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3tramlock/

## Design

Pass the lock with both gates clear, ahead of the other crew. A scrape fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
