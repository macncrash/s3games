# S3 LUGEBUOY

In the luge, you round the buoys and return to the same dock. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3lugebuoy/

## Design

Round the buoys and return to the same dock. A fast circuit that finishes at the wrong dock fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
