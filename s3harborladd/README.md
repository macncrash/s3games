# S3 HARBORLADD

At the harbor, you reach the far ladder. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3harborladd/

## Design

The far ladder is the job. Stopping short of it ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
