# S3 SALLYBANN

You have the sally. The job is to bring the banner back. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3sallybann/

## Design

Bring the banner back to the sally. Dropping it ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
