# S3 HOOPMARK

Play hoop until a finished mark ends it. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3hoopmark/

## Design

The gold coin is the mark. A swish on the mark and lifting the coin finishes it. The rest of a game is not the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
