# S3 GLIDERBUOY

Take the glider and round the buoys and return to the same dock. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3gliderbuoy/

## Design

Round the buoys and set down on the same dock ahead of the other crew. A fast circuit that finishes at the wrong dock fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
