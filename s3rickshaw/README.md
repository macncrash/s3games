# S3 RICKSHAW

One fare, three turns. Don't tip the cab.

Play it in the browser: https://macncrash.github.io/s3games/play/s3rickshaw/

## Design

One fare, three turns, and the cab has to stay up. A tip ends the ride even if you made the turns.

The browser build is one file. The link above is that file, not a capture of a desktop session.
