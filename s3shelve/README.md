# S3 SHELVE

One cart. A book in the wrong row comes back.

Play it in the browser: https://macncrash.github.io/s3games/play/s3shelve/

## Design

A book in the wrong row comes back, and the third return loses the cart. The win is an empty cart, not a pile of books you managed to keep.

The browser build is one file. The link above is that file, not a capture of a desktop session.
