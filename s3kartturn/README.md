# S3 KARTTURN

In the kart, you make the three turns without tipping. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3kartturn/

## Design

Three turns without tipping. One tip ends the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
