# S3 HARBORDOOR

You have the harbor. The job is to hold the door for three minutes. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3harbordoor/

## Design

The door has to hold, and the hull has to stay whole. Opening it early ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
