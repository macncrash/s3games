# S3 REARGUARD

Walk the column back. The fight is behind you.

Play it in the browser: https://macncrash.github.io/s3games/play/s3rearguard/

## Design

The column getting home is the win. The fight is on the road behind it, and a score that loses the column is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
