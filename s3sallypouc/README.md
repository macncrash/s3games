# S3 SALLYPOUC

One sally. Carry the pouch across. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3sallypouc/

## Design

Carry the pouch across on the one sally. Dropping it ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
