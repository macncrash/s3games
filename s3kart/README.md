# S3 KART

Eight laps of one oval. Finish ahead of the pack.

Play it in the browser: https://macncrash.github.io/s3games/play/s3kart/

## Design

Eight laps of one oval. The pack is the opponent, so a clean lap in last place is still a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
