# S3 LANTERNMARK

Play lantern until a finished mark ends it. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3lanternmark/

## Design

Close the gold lamp in order. A lamp left open is still the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
