# S3 BUSBOX

In the bus, you stop inside the box. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3busbox/

## Design

Stop inside the box at the end of the leg. Outside the box fails it.

The browser build is one file. The link above is that file, not a capture of a desktop session.
