# S3 KEYSGOLD

A short keys. You are done when only the gold counts double.

Play it in the browser: https://macncrash.github.io/s3games/play/s3keysgold/

## Design

Only the gold counts double, and the line is 150. Cream hits do not buy the double.

The browser build is one file. The link above is that file, not a capture of a desktop session.
