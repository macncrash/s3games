# S3 ARCHCHIME

Play arch until the hour has to chime. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3archchime/

## Design

The hour has to chime. An arrow before the hour is not this cartridge.

The browser build is one file. The link above is that file, not a capture of a desktop session.
