# S3 BLITZ

A trench run. Ammunition is the clock.

Play it in the browser: https://macncrash.github.io/s3games/play/s3blitz/

## Design

Ammunition is the clock. You do not get a separate timer. When the magazine is gone, the trench is over.

The browser build is one file. The link above is that file, not a capture of a desktop session.
