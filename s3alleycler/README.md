# S3 ALLEYCLER

One alley. Clear the ground before the clock dies. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3alleycler/

## Design

Clear the ground before the clock dies. A clean alley after the clock is already over.

The browser build is one file. The link above is that file, not a capture of a desktop session.
