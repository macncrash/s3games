# S3 SKI

Gates on a downhill. Miss three and the run is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3ski/

## Design

Three missed gates end the run, so the line is a budget. Speed is useless if you spend the budget early.

The browser build is one file. The link above is that file, not a capture of a desktop session.
