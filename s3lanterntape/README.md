# S3 LANTERNTAPE

A short lantern. You are done when the drawer has to match the tape.

Play it in the browser: https://macncrash.github.io/s3games/play/s3lanterntape/

## Design

The drawer has to match the tape, then the lantern shuts. A line that does not match is still open.

The browser build is one file. The link above is that file, not a capture of a desktop session.
