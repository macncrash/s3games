# S3 SAFECHIME

Safe: the hour has to chime. That is the whole cartridge.

Play it in the browser: https://macncrash.github.io/s3games/play/s3safechime/

## Design

The hour has to chime at 12:00:00. A near miss on the tumblers is still short.

The browser build is one file. The link above is that file, not a capture of a desktop session.
