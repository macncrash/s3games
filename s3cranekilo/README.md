# S3 CRANEKILO

In the crane, you finish the kilometer without touching wheels. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3cranekilo/

## Design

Finish the kilometer without touching a wheel. A scrape spends the run even if you make the distance.

The browser build is one file. The link above is that file, not a capture of a desktop session.
