# S3 CLIFFBUOY

The cliff has one job: round the buoys and return to the same dock.

Play it in the browser: https://macncrash.github.io/s3games/play/s3cliffbuoy/

## Design

Round the buoys and return to the same dock. A circuit that finishes at the wrong dock fails the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
