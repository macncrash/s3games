# S3 PALISADEPOUC

One palisade. Carry the pouch across. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3palisadepouc/

## Design

Carry the pouch across the palisade. Stopping in the middle is not across.

The browser build is one file. The link above is that file, not a capture of a desktop session.
