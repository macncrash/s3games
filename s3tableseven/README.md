# S3 TABLESEVEN

Play table until first to seven. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3tableseven/

## Design

First to seven. A leave that looks close and is still under seven is not the game.

The browser build is one file. The link above is that file, not a capture of a desktop session.
