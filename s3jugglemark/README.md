# S3 JUGGLEMARK

A short juggle. You are done when a finished mark ends it.

Play it in the browser: https://macncrash.github.io/s3games/play/s3jugglemark/

## Design

The gold mark is the end. Extra catches after a finished mark are not the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
