# S3 SHUFFLEBELL

Play shuffle until the bell rings before the third try dies. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3shufflebell/

## Design

The bell has to ring before the third try dies. A later slide is already over.

The browser build is one file. The link above is that file, not a capture of a desktop session.
