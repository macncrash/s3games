# S3 DEPOTPOUC

One depot. Carry the pouch across. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3depotpouc/

## Design

The pouch has to cross the depot. Reaching the far side without it is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
