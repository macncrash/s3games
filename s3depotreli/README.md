# S3 DEPOTRELI

One depot. Hold until the relief bell. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3depotreli/

## Design

Hold the depot until the relief bell. Surviving the watch and missing the bell is not relief.

The browser build is one file. The link above is that file, not a capture of a desktop session.
