# S3 FLAK

The deck, the sky, a finite magazine.

Play it in the browser: https://macncrash.github.io/s3games/play/s3flak/

## Design

The deck, the sky, a finite magazine. Splashing planes with no shells left, or keeping shells while the deck is hit, both fail.

The browser build is one file. The link above is that file, not a capture of a desktop session.
