# S3 CURLMARK

Play curl until a finished mark ends it. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3curlmark/

## Design

The gold coin is the mark, and lifting the stone after the draw finishes it. The rest of an end is not the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
