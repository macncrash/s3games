# S3 BARGETURN

The barge has one job: make the three turns without tipping.

Play it in the browser: https://macncrash.github.io/s3games/play/s3bargeturn/

## Design

Three bends without tipping. Letting the cargo slide too far fails the run.

The browser build is one file. The link above is that file, not a capture of a desktop session.
