# S3 CLIFFPASS

Take the cliff and clear the pass before the storm clock. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3cliffpass/

## Design

Clear the pass ahead of the other crew. A late crest fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
