# S3 ORCHARDPACE

One orchard. Wait until the third pace before you fire. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3orchardpace/

## Design

Wait for the third pace, then fire. An earlier shot is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
