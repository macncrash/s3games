# S3 ARCHMARK

A short arch. You are done when a finished mark ends it.

Play it in the browser: https://macncrash.github.io/s3games/play/s3archmark/

## Design

The gold arrow is the mark, and lifting it finishes the mark. The rest of an end is not the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
