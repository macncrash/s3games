# S3 CISTERNPOUC

At the cistern, you carry the pouch across. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3cisternpouc/

## Design

Carry the pouch across the cistern. Stopping in the middle is not across.

The browser build is one file. The link above is that file, not a capture of a desktop session.
