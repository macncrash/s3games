# S3 RIDGEPOUC

You have the ridge. The job is to carry the pouch across. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3ridgepouc/

## Design

The pouch has to cross the ridge. Reaching the far side without it is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
