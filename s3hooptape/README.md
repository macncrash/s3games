# S3 HOOPTAPE

A short hoop. You are done when the drawer has to match the tape.

Play it in the browser: https://macncrash.github.io/s3games/play/s3hooptape/

## Design

The drawer has to match the tape, and that closes the short hoop. A make that pays the same and is not on the tape stays out.

The browser build is one file. The link above is that file, not a capture of a desktop session.
