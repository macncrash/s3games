# S3 CULVERTBANN

One culvert. Bring the banner back. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3culvertbann/

## Design

Bring the banner back through the culvert. Dropping it ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
