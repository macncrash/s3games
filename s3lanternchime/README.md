# S3 LANTERNCHIME

Lantern: the hour has to chime. That is the whole cartridge.

Play it in the browser: https://macncrash.github.io/s3games/play/s3lanternchime/

## Design

The hour has to chime at 12:00:00. Lamps that miss the hour do not end it.

The browser build is one file. The link above is that file, not a capture of a desktop session.
