# S3 RIDGEDAWN

One ridge. Keep the flares lit until dawn. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3ridgedawn/

## Design

The flares have to stay lit until dawn. A dark flare before dawn is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
