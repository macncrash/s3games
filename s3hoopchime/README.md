# S3 HOOPCHIME

Hoop: the hour has to chime. That is the whole cartridge.

Play it in the browser: https://macncrash.github.io/s3games/play/s3hoopchime/

## Design

The hour has to chime. A made shot before the hour is not this cartridge.

The browser build is one file. The link above is that file, not a capture of a desktop session.
