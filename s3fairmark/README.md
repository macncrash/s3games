# S3 FAIRMARK

A short fair. You are done when a finished mark ends it.

Play it in the browser: https://macncrash.github.io/s3games/play/s3fairmark/

## Design

The gold coin is the mark. A ring on the gold bottle and lifting the coin finishes it. The rest of the booth is not the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
