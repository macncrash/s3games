# S3 WHARFPOUC

You have the wharf. The job is to carry the pouch across. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3wharfpouc/

## Design

Carry the pouch across the wharf. Stopping in the middle is not across.

The browser build is one file. The link above is that file, not a capture of a desktop session.
