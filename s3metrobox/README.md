# S3 METROBOX

Take the metro and stop inside the box. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3metrobox/

## Design

Stop inside the box ahead of the other crew. Rolling past the box fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
