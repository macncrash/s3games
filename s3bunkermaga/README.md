# S3 BUNKERMAGA

You have the bunker. The job is to make the magazine last longer than the raid. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3bunkermaga/

## Design

One magazine has to outlast the raid. Emptying it before the raid ends fails the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
