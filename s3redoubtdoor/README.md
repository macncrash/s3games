# S3 REDOUBTDOOR

At the redoubt, you hold the door for three minutes. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3redoubtdoor/

## Design

Hold the door for three minutes. Breaking early ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
