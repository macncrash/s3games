# S3 RICKSHAWMARK

Take the rickshaw and set down on the mark. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3rickshawmark/

## Design

Set down on the mark ahead of the other crew. Close and still off the mark fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
