# S3 SPANCLER

At the span, you clear the ground before the clock dies. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3spancler/

## Design

Clear the ground before the clock dies. A clean span after the clock is already over.

The browser build is one file. The link above is that file, not a capture of a desktop session.
