# S3 CRANE

Three crates, ship to mark. A drop fails the shift.

Play it in the browser: https://macncrash.github.io/s3games/play/s3crane/

## Design

Three crates on the mark. A drop is a failed shift, not a crate you pick up again for free.

The browser build is one file. The link above is that file, not a capture of a desktop session.
