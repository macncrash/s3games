# S3 WHARFCLER

At the wharf, you clear the ground before the clock dies. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3wharfcler/

## Design

Clear the ground before the clock dies. Anything left is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
