# S3 PALISADEBANN

You have the palisade. The job is to bring the banner back. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3palisadebann/

## Design

Bring the banner back to the palisade. Stopping short of home is not done.

The browser build is one file. The link above is that file, not a capture of a desktop session.
