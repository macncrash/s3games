# S3 SCULLLANE

Take the scull and stay in the lane for the whole leg. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3sculllane/

## Design

Stay inside the buoyed lane for the whole leg. Leaving the lane fails it.

The browser build is one file. The link above is that file, not a capture of a desktop session.
