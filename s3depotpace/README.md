# S3 DEPOTPACE

You have the depot. The job is to wait until the third pace before you fire. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3depotpace/

## Design

Fire on the third pace. An earlier shot that still holds the depot is not the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
