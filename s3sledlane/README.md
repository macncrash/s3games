# S3 SLEDLANE

In the sled, you stay in the lane for the whole leg. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3sledlane/

## Design

Stay in the lane for the whole leg. Leaving the lane fails it even if you reach the gate.

The browser build is one file. The link above is that file, not a capture of a desktop session.
