# S3 LOTPOUC

One lot. Carry the pouch across. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3lotpouc/

## Design

The pouch has to cross the lot. Reaching the middle and stopping is not across.

The browser build is one file. The link above is that file, not a capture of a desktop session.
