# S3 DART

Five-oh-one, double out. The board is the whole game.

Play it in the browser: https://macncrash.github.io/s3games/play/s3dart/

## Design

501 and double-out. The board is the whole game, and you cannot finish on a single. The last dart has to be the double you chose.

The browser build is one file. The link above is that file, not a capture of a desktop session.
