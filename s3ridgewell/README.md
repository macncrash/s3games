# S3 RIDGEWELL

One ridge. Keep the well standing through three waves. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3ridgewell/

## Design

The well has to stand through three waves. A stone that gets through is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
