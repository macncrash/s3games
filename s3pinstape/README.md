# S3 PINSTAPE

A short pins. You are done when the drawer has to match the tape.

Play it in the browser: https://macncrash.github.io/s3games/play/s3pinstape/

## Design

The drawer has to match the tape, and that closes the short rack. A score that does not match the tape is still open.

The browser build is one file. The link above is that file, not a capture of a desktop session.
