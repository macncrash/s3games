# S3 KEELLOCK

Take the keel and pass the lock without scraping a gate. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3keellock/

## Design

Pass the lock without scraping a gate. A scrape fails the leg.
