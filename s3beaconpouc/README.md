# S3 BEACONPOUC

You have the beacon. The job is to carry the pouch across. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3beaconpouc/

## Design

Carry the pouch across under the beacon. Dropping it ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
