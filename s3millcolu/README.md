# S3 MILLCOLU

One mill. Stop the column on the road. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3millcolu/

## Design

Stop the column on the road. A wagon that still gets through is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
