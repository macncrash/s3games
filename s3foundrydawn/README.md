# S3 FOUNDRYDAWN

At the foundry, you keep the flares lit until dawn. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3foundrydawn/

## Design

Keep the flares lit until dawn. A dark flare is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
