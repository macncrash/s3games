# S3 CISTERNCOLU

You have the cistern. The job is to stop the column on the road. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3cisterncolu/

## Design

Stop the column on the road. A column still rolling is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
