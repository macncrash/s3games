# S3 BIKE

One kilometer. Don't touch wheels.

Play it in the browser: https://macncrash.github.io/s3games/play/s3bike/

## Design

One kilometer and the wheels must not touch. Rubbing is a disqualification, not a racing incident you can shrug off.

The browser build is one file. The link above is that file, not a capture of a desktop session.
