# S3 BUSMARK

In the bus, you set down on the mark. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3busmark/

## Design

Set the bus on the mark. Close and still off the mark fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
