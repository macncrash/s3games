# S3 SCULLLOCK

In the scull, you pass the lock without scraping a gate. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3sculllock/

## Design

Row through the lock with the gates clear and the end made. A scrape fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
