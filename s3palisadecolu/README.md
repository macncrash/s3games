# S3 PALISADECOLU

At the palisade, you stop the column on the road. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3palisadecolu/

## Design

Stop the column on the road. A column still rolling is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
