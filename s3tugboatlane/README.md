# S3 TUGBOATLANE

The tugboat has one job: stay in the lane for the whole leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3tugboatlane/

## Design

Stay in the lane for the whole leg. Leaving the lane fails it even if you reach the gate.

The browser build is one file. The link above is that file, not a capture of a desktop session.
