# S3 TUG

Berth the ship. The pilings are a fail.

Play it in the browser: https://macncrash.github.io/s3games/play/s3tug/

## Design

The ship has to sit in the slip. Touching a piling is a fail, so the last meters are slower than the approach.

The browser build is one file. The link above is that file, not a capture of a desktop session.
