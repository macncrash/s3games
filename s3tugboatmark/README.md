# S3 TUGBOATMARK

In the tugboat, you set down on the mark. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3tugboatmark/

## Design

The bow has to be on the mark. Close to the mark fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
