# S3 MAILVANBOX

Take the mailvan and stop inside the box. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3mailvanbox/

## Design

Stop inside the box before the other crew. Stopping short of the box fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
