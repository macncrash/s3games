# S3 LUGEMARK

Take the luge and set down on the mark. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3lugemark/

## Design

Set down on the mark ahead of the other crew. Close to the mark is still a missed leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
