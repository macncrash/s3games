# S3 SALLYPACE

You have the sally. The job is to wait until the third pace before you fire. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3sallypace/

## Design

Fire on the third pace. An early shot is not done.

The browser build is one file. The link above is that file, not a capture of a desktop session.
