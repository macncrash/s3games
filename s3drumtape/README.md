# S3 DRUMTAPE

Drum: the drawer has to match the tape. That is the whole cartridge.

Play it in the browser: https://macncrash.github.io/s3games/play/s3drumtape/

## Design

The drawer has to match the tape, then you leave. A near match is still a miss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
