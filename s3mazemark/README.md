# S3 MAZEMARK

A short maze. You are done when a finished mark ends it.

Play it in the browser: https://macncrash.github.io/s3games/play/s3mazemark/

## Design

The gold coin is the mark. Standing on it and lifting the coin finishes the mark. The rest of the hedge is not the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
