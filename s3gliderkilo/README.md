# S3 GLIDERKILO

The glider has one job: finish the kilometer without touching wheels.

Play it in the browser: https://macncrash.github.io/s3games/play/s3gliderkilo/

## Design

Finish the kilometer with the wheels untouched. A scrape spends the run even if you make the distance.

The browser build is one file. The link above is that file, not a capture of a desktop session.
