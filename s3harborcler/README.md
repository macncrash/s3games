# S3 HARBORCLER

You have the harbor. The job is to clear the ground before the clock dies. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3harborcler/

## Design

Clear the quay before the clock dies. A clean quay after the clock is already over.

The browser build is one file. The link above is that file, not a capture of a desktop session.
