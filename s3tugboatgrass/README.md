# S3 TUGBOATGRASS

The tugboat has one job: land on the grass and come to a full stop.

Play it in the browser: https://macncrash.github.io/s3games/play/s3tugboatgrass/

## Design

Land on the grass and come to a full stop. A touch that keeps rolling fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
