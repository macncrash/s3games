# S3 MINE

A cart in a tunnel. Shoot the props, miss the walls.

Play it in the browser: https://macncrash.github.io/s3games/play/s3mine/

## Design

The props are the targets and the walls are the fail. A cart that survives by not shooting has not finished the day.

The browser build is one file. The link above is that file, not a capture of a desktop session.
