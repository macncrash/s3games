# S3 GLIDERPLAT

In the glider, you stop level with the platform. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3gliderplat/

## Design

Stop level with the platform. Close is not level.

The browser build is one file. The link above is that file, not a capture of a desktop session.
