# S3 REDOUBTPOUC

You have the redoubt. The job is to carry the pouch across. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3redoubtpouc/

## Design

Carry the pouch across the redoubt. Stopping in the middle is not across.

The browser build is one file. The link above is that file, not a capture of a desktop session.
