# S3 SOLITAIRE

One deal. Clear the tableau.

Play it in the browser: https://macncrash.github.io/s3games/play/s3solitaire/

## Design

One deal, face up, aces through sevens. Build down red on black and send them home in suit. A second shuffle is not this game.

The browser build is one file. The link above is that file, not a capture of a desktop session.
