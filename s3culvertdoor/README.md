# S3 CULVERTDOOR

One culvert. Hold the door for three minutes. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3culvertdoor/

## Design

Hold the door for three minutes. Dropping it early is not done.

The browser build is one file. The link above is that file, not a capture of a desktop session.
