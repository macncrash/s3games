# S3 BARGELANE

In the barge, you stay in the lane for the whole leg. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3bargelane/

## Design

Stay in the canal for the whole leg and still make the end. Leaving the lane fails it.

The browser build is one file. The link above is that file, not a capture of a desktop session.
