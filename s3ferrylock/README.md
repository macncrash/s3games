# S3 FERRYLOCK

In the ferry, you pass the lock without scraping a gate. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3ferrylock/

## Design

Pass the lock without scraping a gate. Missing the far end fails the leg even if the leaves never touched the hull.

The browser build is one file. The link above is that file, not a capture of a desktop session.
