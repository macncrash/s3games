# S3 TUGBOATLOCK

Take the tugboat and pass the lock without scraping a gate. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3tugboatlock/

## Design

Pass the lock without scraping a gate, ahead of the other crew. A scrape fails the pass even if you made it through.

The browser build is one file. The link above is that file, not a capture of a desktop session.
