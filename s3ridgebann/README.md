# S3 RIDGEBANN

At the ridge, you bring the banner back. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3ridgebann/

## Design

The banner has to come back onto the ridge. Reaching it and staying off the ridge ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
