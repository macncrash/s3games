# S3 LUGEKILO

Take the luge and finish the kilometer without touching wheels. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3lugekilo/

## Design

Finish the kilometer without touching a wheel, ahead of the other crew. A scrape spends the run.

The browser build is one file. The link above is that file, not a capture of a desktop session.
