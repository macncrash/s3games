# S3 BARGEBOX

Take the barge and stop inside the box. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3bargebox/

## Design

Stop inside the box before the other crew. Close to the box is still outside.

The browser build is one file. The link above is that file, not a capture of a desktop session.
