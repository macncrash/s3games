# S3 SKIFFLANE

In the skiff, you stay in the lane for the whole leg. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3skifflane/

## Design

Stay between the buoys for the whole leg. Leaving the lane fails it even if you reach the gate.

The browser build is one file. The link above is that file, not a capture of a desktop session.
