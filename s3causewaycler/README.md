# S3 CAUSEWAYCLER

At the causeway, you clear the ground before the clock dies. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3causewaycler/

## Design

Clear the ground before the clock dies. A clean causeway after the clock is already over.

The browser build is one file. The link above is that file, not a capture of a desktop session.
