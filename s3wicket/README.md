# S3 WICKET

Six balls. Hit the wicket or clear the rope.

Play it in the browser: https://macncrash.github.io/s3games/play/s3wicket/

## Design

Six balls. You need the wicket and the rope, not one of them. A quiet over that does neither is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
