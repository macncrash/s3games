# S3 SLEDLOCK

The sled has one job: pass the lock without scraping a gate.

Play it in the browser: https://macncrash.github.io/s3games/play/s3sledlock/

## Design

Pass the lock without scraping a gate. A scrape fails the run even if you made it through.

The browser build is one file. The link above is that file, not a capture of a desktop session.
