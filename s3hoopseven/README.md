# S3 HOOPSEVEN

A short hoop. You are done when first to seven.

Play it in the browser: https://macncrash.github.io/s3games/play/s3hoopseven/

## Design

First to seven. A leave that looks close and is still under seven is not the game.

The browser build is one file. The link above is that file, not a capture of a desktop session.
