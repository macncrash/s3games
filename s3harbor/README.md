# S3 HARBOR

One channel. The forts shoot back. The magazine is finite.

Play it in the browser: https://macncrash.github.io/s3games/play/s3harbor/

## Design

One channel, the forts shoot back, and the magazine is finite. Saving rounds and not clearing the forts is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
