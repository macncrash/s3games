# S3 YARDPACE

One yard. Wait until the third pace before you fire. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3yardpace/

## Design

Fire on the third pace. An earlier shot that still holds the yard is not the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
