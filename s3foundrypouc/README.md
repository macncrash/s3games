# S3 FOUNDRYPOUC

One foundry. Carry the pouch across. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3foundrypouc/

## Design

Carry the pouch across the foundry. Stopping in the middle is not across.

The browser build is one file. The link above is that file, not a capture of a desktop session.
