# S3 INKWELLMARK

Play inkwell until a finished mark ends it. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3inkwellmark/

## Design

A finished mark ends it. An open stroke is still a miss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
