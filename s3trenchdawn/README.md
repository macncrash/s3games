# S3 TRENCHDAWN

You have the trench. The job is to keep the flares lit until dawn. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3trenchdawn/

## Design

Keep the flares lit until dawn. A dark flare is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
