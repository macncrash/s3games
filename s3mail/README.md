# S3 MAIL

The box gets the paper. Don't miss the turn.

Play it in the browser: https://macncrash.github.io/s3games/play/s3mail/

## Design

The paper has to land in the box, and the turn has to be made. A fast street that misses either one is not a finished route.

The browser build is one file. The link above is that file, not a capture of a desktop session.
