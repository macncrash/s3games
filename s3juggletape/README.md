# S3 JUGGLETAPE

Juggle: the drawer has to match the tape. That is the whole cartridge.

Play it in the browser: https://macncrash.github.io/s3games/play/s3juggletape/

## Design

The drawer has to match the tape, then you leave. A line that does not match is still open.

The browser build is one file. The link above is that file, not a capture of a desktop session.
