# S3 PLOW

Clear the pass before the storm clock hits zero.

Play it in the browser: https://macncrash.github.io/s3games/play/s3plow/

## Design

The pass has to be clear before the storm hits zero. A pretty stripe that is unfinished when the clock dies is a fail.

The browser build is one file. The link above is that file, not a capture of a desktop session.
