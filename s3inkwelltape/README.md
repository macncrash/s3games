# S3 INKWELLTAPE

A short inkwell. You are done when the drawer has to match the tape.

Play it in the browser: https://macncrash.github.io/s3games/play/s3inkwelltape/

## Design

The drawer has to match the tape, then you leave. A near match is still a miss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
