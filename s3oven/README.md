# S3 OVEN

Six loaves. Burn one and the morning fails.

Play it in the browser: https://macncrash.github.io/s3games/play/s3oven/

## Design

Six loaves, and a burned loaf fails the morning. Speed that ruins one loaf is not a finished bake.

The browser build is one file. The link above is that file, not a capture of a desktop session.
