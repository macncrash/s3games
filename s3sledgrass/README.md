# S3 SLEDGRASS

In the sled, you land on the grass and come to a full stop. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3sledgrass/

## Design

Land on the grass and come to a full stop. A touch that keeps rolling fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
