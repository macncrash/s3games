# S3 CRANEBOOM

In the crane, you deliver the drive to the boom. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3craneboom/

## Design

Set the drive on the end of the boom. Reaching the boom without setting it down fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
