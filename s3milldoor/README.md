# S3 MILLDOOR

At the mill, you hold the door for three minutes. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3milldoor/

## Design

Hold the door for three minutes. A breach before the clock is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
