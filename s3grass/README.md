# S3 GRASS

Three circuits of a grass strip. The third landing is a full stop.

Play it in the browser: https://macncrash.github.io/s3games/play/s3grass/

## Design

Three left-hand circuits of the grass strip. The third landing has to be a full stop. A touch-and-go on the last circuit is not a pass.

The browser build is one file. The link above is that file, not a capture of a desktop session.
