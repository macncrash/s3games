# S3 FERRYBUOY

Take the ferry and round the buoys and return to the same dock. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3ferrybuoy/

## Design

Round the buoys to port and stop in the same slip ahead of the other crew. A fast circuit that finishes at the wrong dock fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
