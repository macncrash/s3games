# S3 FOUNDRYDOOR

You have the foundry. The job is to hold the door for three minutes. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3foundrydoor/

## Design

Hold the door for three minutes. Breaking early ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
