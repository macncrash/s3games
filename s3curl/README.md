# S3 CURL

Four ends. Closest to the button takes the end.

Play it in the browser: https://macncrash.github.io/s3games/play/s3curl/

## Design

Four ends, closest to the button. Weight and line are the only tools, and a stone that is close and guarded beats a stone that is closer and naked.

The browser build is one file. The link above is that file, not a capture of a desktop session.
