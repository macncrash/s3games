# S3 LOTCOLU

At the lot, you stop the column on the road. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3lotcolu/

## Design

The column has to stop on the road. A van that gets through is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
