# S3 WICKETMARK

Wicket: a finished mark ends it. That is the whole cartridge.

Play it in the browser: https://macncrash.github.io/s3games/play/s3wicketmark/

## Design

The gold coin is the bowler's mark. Hitting the wicket on the mark and lifting the coin finishes it. The rest of an over is not the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
