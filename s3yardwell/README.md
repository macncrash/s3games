# S3 YARDWELL

You have the yard. The job is to keep the well standing through three waves. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3yardwell/

## Design

The well has to stand through three waves. A breach is a loss even if you are still in the yard.

The browser build is one file. The link above is that file, not a capture of a desktop session.
