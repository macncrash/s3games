# S3 GATEBANN

One gate. Bring the banner back. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3gatebann/

## Design

The banner has to come back through the gate. Reaching it and staying on the far side is not done.

The browser build is one file. The link above is that file, not a capture of a desktop session.
