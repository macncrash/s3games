# S3 REDOUBTMAGA

You have the redoubt. The job is to make the magazine last longer than the raid. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3redoubtmaga/

## Design

The magazine has to outlast the raid. Empty before the last stop ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
