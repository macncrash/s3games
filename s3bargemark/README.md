# S3 BARGEMARK

Take the barge and set down on the mark. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3bargemark/

## Design

Set down on the painted mark before the other crew. Close to the mark, or late, fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
