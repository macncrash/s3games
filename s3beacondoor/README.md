# S3 BEACONDOOR

At the beacon, you hold the door for three minutes. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3beacondoor/

## Design

Hold the door for three minutes. Dropping it early is not done.

The browser build is one file. The link above is that file, not a capture of a desktop session.
