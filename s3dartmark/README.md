# S3 DARTMARK

A short dart. You are done when a finished mark ends it.

Play it in the browser: https://macncrash.github.io/s3games/play/s3dartmark/

## Design

A treble 20 closes the 20 and finishes the mark. The rest of a visit is not the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
