# S3 QUILLTAPE

Play quill until the drawer has to match the tape. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3quilltape/

## Design

The drawer has to match the tape, then you leave. A near match is still a miss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
