# S3 HEADERBOOM

The header has one job: deliver the drive to the boom.

Play it in the browser: https://macncrash.github.io/s3games/play/s3headerboom/

## Design

The drive has to sit on the boom. Reaching the boom without setting it down fails the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
