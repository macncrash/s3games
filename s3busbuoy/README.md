# S3 BUSBUOY

The bus has one job: round the buoys and return to the same dock.

Play it in the browser: https://macncrash.github.io/s3games/play/s3busbuoy/

## Design

Round the buoys and return to the same dock. Missing the dock fails the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
