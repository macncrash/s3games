# S3 JUGGLEGOLD

Play juggle until only the gold counts double. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3jugglegold/

## Design

Only the gold counts double. Cream catches do not buy the line.

The browser build is one file. The link above is that file, not a capture of a desktop session.
