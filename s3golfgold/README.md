# S3 GOLFGOLD

Golf: only the gold counts double. That is the whole cartridge.

Play it in the browser: https://macncrash.github.io/s3games/play/s3golfgold/

## Design

The line is 6, and only the gold counts double. Cream shots do not buy the double.

The browser build is one file. The link above is that file, not a capture of a desktop session.
