# S3 GLIDERLANE

Take the glider and stay in the lane for the whole leg. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3gliderlane/

## Design

Stay between the rails for the whole leg. Leaving the lane fails it even if you reach the gate.

The browser build is one file. The link above is that file, not a capture of a desktop session.
