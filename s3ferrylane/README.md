# S3 FERRYLANE

Take the ferry and stay in the lane for the whole leg. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3ferrylane/

## Design

Stay inside the buoyed channel for the whole crossing. Leaving the lane fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
