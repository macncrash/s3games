# S3 PINS

Ten frames. Knock them down. A mark finishes the game.

Play it in the browser: https://macncrash.github.io/s3games/play/s3pins/

## Design

A mark is ten frames, not a high score you can grind. The pocket and the arrows are the whole decision, so a spare is a recovery and a strike is the only way to stay clean.

The browser build is one file. The link above is that file, not a capture of a desktop session.
