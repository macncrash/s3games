# S3 SALLYMAGA

One sally. Make the magazine last longer than the raid. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3sallymaga/

## Design

The magazine has to outlast the raid. Running dry first ends the watch.
