# S3 DEPOTCLER

You have the depot. The job is to clear the ground before the clock dies. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3depotcler/

## Design

Clear the ground before the clock dies. A clean yard after the clock is already over.

The browser build is one file. The link above is that file, not a capture of a desktop session.
