# S3 TUGBOATPLAT

Take the tugboat and stop level with the platform. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3tugboatplat/

## Design

Stop level with the platform, ahead of the other crew. Close is not level.

The browser build is one file. The link above is that file, not a capture of a desktop session.
