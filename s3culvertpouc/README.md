# S3 CULVERTPOUC

At the culvert, you carry the pouch across. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3culvertpouc/

## Design

Carry the pouch across. Dropping it ends the watch.
