# S3 MUSHBUOY

Take the mush and round the buoys and return to the same dock. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3mushbuoy/

## Design

Round the buoys and beat the other crew back to the same dock. Missing the dock fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
