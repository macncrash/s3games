# S3 OVENCHIME

A short oven. You are done when the hour has to chime.

Play it in the browser: https://macncrash.github.io/s3games/play/s3ovenchime/

## Design

The hour has to chime at 12:00:00. A near miss is still short.

The browser build is one file. The link above is that file, not a capture of a desktop session.
