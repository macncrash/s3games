# S3 LOTDAWN

At the lot, you keep the flares lit until dawn. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3lotdawn/

## Design

Keep the flares lit until dawn. A dark lot ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
