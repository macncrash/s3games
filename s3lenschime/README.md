# S3 LENSCHIME

Play lens until the hour has to chime. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3lenschime/

## Design

The hour has to chime. Leaving before the chime is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
