# S3 DARTTAPE

Dart: the drawer has to match the tape. That is the whole cartridge.

Play it in the browser: https://macncrash.github.io/s3games/play/s3darttape/

## Design

The drawer has to match the tape, then you leave. A score that does not match the tape is still open.

The browser build is one file. The link above is that file, not a capture of a desktop session.
