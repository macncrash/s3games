# S3 GRANARYCLER

One granary. Clear the ground before the clock dies. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3granarycler/

## Design

Clear the ground before the clock dies. A late clear is not done.

The browser build is one file. The link above is that file, not a capture of a desktop session.
