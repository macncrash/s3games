# S3 CABBOOM

In the cab, you deliver the drive to the boom. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3cabboom/

## Design

The drive has to land on the boom. Missing the boom fails the leg even if you arrive.

The browser build is one file. The link above is that file, not a capture of a desktop session.
