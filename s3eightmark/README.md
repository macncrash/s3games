# S3 EIGHTMARK

Eight: a finished mark ends it. That is the whole cartridge.

Play it in the browser: https://macncrash.github.io/s3games/play/s3eightmark/

## Design

The coin is the mark. Pocketing the 8 in the top side and lifting the coin finishes it. The rest of a rack is not the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
