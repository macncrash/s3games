# S3 RICKSHAWPLAT

The rickshaw has one job: stop level with the platform.

Play it in the browser: https://macncrash.github.io/s3games/play/s3rickshawplat/

## Design

Stop level with the platform. Short or past the platform fails the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
