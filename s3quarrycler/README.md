# S3 QUARRYCLER

You have the quarry. The job is to clear the ground before the clock dies. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3quarrycler/

## Design

Clear the ground before the clock dies. A clean quarry after the clock is already over.

The browser build is one file. The link above is that file, not a capture of a desktop session.
