# S3 QUARRYPACE

You have the quarry. The job is to wait until the third pace before you fire. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3quarrypace/

## Design

Wait for the third pace, then fire. An earlier shot is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
