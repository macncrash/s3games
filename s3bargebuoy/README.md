# S3 BARGEBUOY

In the barge, you round the buoys and return to the same dock. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3bargebuoy/

## Design

Round the buoys to port and stop in the same dock. A fast circuit that finishes at the wrong dock fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
