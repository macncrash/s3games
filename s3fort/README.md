# S3 FORT

Hold the gate until the clock dies.

Play it in the browser: https://macncrash.github.io/s3games/play/s3fort/

## Design

The gate is the score. You are not asked to clear the field. You are asked to still be holding the gate when the clock dies.

The browser build is one file. The link above is that file, not a capture of a desktop session.
