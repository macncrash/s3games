# S3 EIGHTCHIME

A short eight. You are done when the hour has to chime.

Play it in the browser: https://macncrash.github.io/s3games/play/s3eightchime/

## Design

The hour has to chime. A sunk ball before the hour is not this cartridge.

The browser build is one file. The link above is that file, not a capture of a desktop session.
