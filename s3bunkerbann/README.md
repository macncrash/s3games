# S3 BUNKERBANN

At the bunker, you bring the banner back. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3bunkerbann/

## Design

The banner has to come back to the bunker. Reaching it and staying away ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
