# S3 TOWERMAGA

At the tower, you make the magazine last longer than the raid. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3towermaga/

## Design

The magazine has to outlast the raid. Burning the rounds and dying with the raid still up is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
