# S3 BOCCESEVEN

Play bocce until first to seven. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3bocceseven/

## Design

First to seven, then leave. A six that looks close is still short.

The browser build is one file. The link above is that file, not a capture of a desktop session.
