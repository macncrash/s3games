# S3 LOTDOOR

You have the lot. The job is to hold the door for three minutes. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3lotdoor/

## Design

Hold the door for the whole watch. A breach before the gate is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
