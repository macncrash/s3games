# S3 VIADUCTDOOR

You have the viaduct. The job is to hold the door for three minutes. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3viaductdoor/

## Design

Hold the door for three minutes. A breach before the clock is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
