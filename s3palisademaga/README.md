# S3 PALISADEMAGA

One palisade. Make the magazine last longer than the raid. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3palisademaga/

## Design

The magazine has to outlast the raid. Empty before the last stop ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
