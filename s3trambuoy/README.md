# S3 TRAMBUOY

The tram has one job: round the buoys and return to the same dock.

Play it in the browser: https://macncrash.github.io/s3games/play/s3trambuoy/

## Design

Round the harbour buoys and tie up at the same dock. A fast circuit that finishes at the wrong dock fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
