# S3 BARGEKILO

Take the barge and finish the kilometer without touching wheels. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3bargekilo/

## Design

Finish the kilometer without touching a wheel. A scrape spends the run even if you make the distance.

The browser build is one file. The link above is that file, not a capture of a desktop session.
