# S3 WHARFWELL

One wharf. Keep the well standing through three waves. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3wharfwell/

## Design

Keep the well standing through three waves. A fallen well is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
