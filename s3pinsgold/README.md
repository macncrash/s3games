# S3 PINSGOLD

Pins: only the gold counts double. That is the whole cartridge.

Play it in the browser: https://macncrash.github.io/s3games/play/s3pinsgold/

## Design

Gold counts double, and the frame has to finish on a double. Cream pins do not buy back a missed double.

The browser build is one file. The link above is that file, not a capture of a desktop session.
