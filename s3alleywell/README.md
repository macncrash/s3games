# S3 ALLEYWELL

You have the alley. The job is to keep the well standing through three waves. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3alleywell/

## Design

The well has to stand through three waves. A breach is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
