# S3 BEACONMAGA

You have the beacon. The job is to make the magazine last longer than the raid. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3beaconmaga/

## Design

The magazine has to outlast the raid. Running dry first ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
