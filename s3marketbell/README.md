# S3 MARKETBELL

A short market. You are done when the bell rings before the third try dies.

Play it in the browser: https://macncrash.github.io/s3games/play/s3marketbell/

## Design

Three tries at the change. The bell has to ring before the third try dies.

The browser build is one file. The link above is that file, not a capture of a desktop session.
