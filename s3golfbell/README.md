# S3 GOLFBELL

Play golf until the bell rings before the third try dies. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3golfbell/

## Design

Three tries at one cup. The bell has to ring before the third try dies.

The browser build is one file. The link above is that file, not a capture of a desktop session.
