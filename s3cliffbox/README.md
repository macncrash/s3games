# S3 CLIFFBOX

In the cliff, you stop inside the box. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3cliffbox/

## Design

Stop inside the box. Stopping short of the box fails the leg.
