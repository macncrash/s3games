# S3 CRANEPASS

Take the crane and clear the pass before the storm clock. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3cranepass/

## Design

Clear the pass before the storm clock. A late crest fails the leg.
