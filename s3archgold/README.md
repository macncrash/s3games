# S3 ARCHGOLD

Play arch until only the gold counts double. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3archgold/

## Design

Only the gold counts double, and the line is 300. Cream arrows do not buy the double.

The browser build is one file. The link above is that file, not a capture of a desktop session.
