# S3 SHELVECHIME

Shelve: the hour has to chime. That is the whole cartridge.

Play it in the browser: https://macncrash.github.io/s3games/play/s3shelvechime/

## Design

The hour has to chime. A shelf that misses the hour is still open.

The browser build is one file. The link above is that file, not a capture of a desktop session.
