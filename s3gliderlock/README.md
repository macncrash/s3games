# S3 GLIDERLOCK

In the glider, you pass the lock without scraping a gate. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3gliderlock/

## Design

Pass the lock without scraping a gate. A scrape fails the leg even if you made it through.

The browser build is one file. The link above is that file, not a capture of a desktop session.
