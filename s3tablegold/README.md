# S3 TABLEGOLD

A short table. You are done when only the gold counts double.

Play it in the browser: https://macncrash.github.io/s3games/play/s3tablegold/

## Design

The line is 4, and only the gold counts double. Cream balls do not buy the double.

The browser build is one file. The link above is that file, not a capture of a desktop session.
