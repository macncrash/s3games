# S3 MARKETMARK

A short market. You are done when a finished mark ends it.

Play it in the browser: https://macncrash.github.io/s3games/play/s3marketmark/

## Design

The gold note is the mark. Exact change finishes it. The rest of the stall is not the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
