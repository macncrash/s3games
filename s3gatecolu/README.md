# S3 GATECOLU

You have the gate. The job is to stop the column on the road. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3gatecolu/

## Design

The column has to stop on the road. A truck that gets through is a loss, whatever else you hit.

The browser build is one file. The link above is that file, not a capture of a desktop session.
