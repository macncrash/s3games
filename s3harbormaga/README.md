# S3 HARBORMAGA

One harbor. Make the magazine last longer than the raid. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3harbormaga/

## Design

The magazine has to outlast the raid. Emptying it before the cutters are done fails the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
