# S3 SPANRELI

You have the span. The job is to hold until the relief bell. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3spanreli/

## Design

Hold the span until the relief bell, then haul it. Surviving the watch and missing the bell is not relief.

The browser build is one file. The link above is that file, not a capture of a desktop session.
