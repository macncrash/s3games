# S3 SALLYDOOR

You have the sally. The job is to hold the door for three minutes. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3sallydoor/

## Design

Hold the door for three minutes. Dropping it early is not done.

The browser build is one file. The link above is that file, not a capture of a desktop session.
