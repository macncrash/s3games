# S3 SALLYLADD

At the sally, you reach the far ladder. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3sallyladd/

## Design

Reach the far ladder. Stopping short of it is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
