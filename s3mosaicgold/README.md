# S3 MOSAICGOLD

Play mosaic until only the gold counts double. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3mosaicgold/

## Design

Only the gold counts double. Bare and cream tiles do not buy the line.

The browser build is one file. The link above is that file, not a capture of a desktop session.
