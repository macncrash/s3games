# S3 TRAMBOOM

In the tram, you deliver the drive to the boom. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3tramboom/

## Design

The drive has to sit on the boom. Reaching the boom without setting it down fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
