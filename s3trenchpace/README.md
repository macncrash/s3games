# S3 TRENCHPACE

One trench. Wait until the third pace before you fire. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3trenchpace/

## Design

Fire on the third pace. An early shot is not done.

The browser build is one file. The link above is that file, not a capture of a desktop session.
