# S3 SIEGE

You are the wall. Stop the rams before the gate breaks.

Play it in the browser: https://macncrash.github.io/s3games/play/s3siege/

## Design

You are the wall. The rams are the problem, and the gate breaking ends it even if you still have people.

The browser build is one file. The link above is that file, not a capture of a desktop session.
