# S3 HELIBUOY

Take the heli and round the buoys and return to the same dock. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3helibuoy/

## Design

Round the buoys and return to the same dock ahead of the other crew.

The browser build is one file. The link above is that file, not a capture of a desktop session.
