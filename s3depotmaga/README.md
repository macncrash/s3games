# S3 DEPOTMAGA

One depot. Make the magazine last longer than the raid. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3depotmaga/

## Design

The magazine has to outlast the raid. Emptying it before the raid ends fails the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
