# S3 SKATEBELL

Play skate until the bell rings before the third try dies. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3skatebell/

## Design

Ring the bell before the third try dies, then leave. A later trick is already over.

The browser build is one file. The link above is that file, not a capture of a desktop session.
