# S3 TUGBOATPASS

Take the tugboat and clear the pass before the storm clock. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3tugboatpass/

## Design

Clear the pass before the storm clock dies, ahead of the other crew. Making the pass with the clock already gone fails it.

The browser build is one file. The link above is that file, not a capture of a desktop session.
