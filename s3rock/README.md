# S3 ROCK

A minute of rocks. The hull is the score.

Play it in the browser: https://macncrash.github.io/s3games/play/s3rock/

## Design

A minute, and the hull is the score. You are not asked to destroy the rocks. You are asked to still be there.

The browser build is one file. The link above is that file, not a capture of a desktop session.
