# S3 SUBKILO

In the sub, you finish the kilometer without touching wheels. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3subkilo/

## Design

Finish the kilometer without touching wheels. One touch fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
