# S3 ALLEYDAWN

You have the alley. The job is to keep the flares lit until dawn. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3alleydawn/

## Design

The flares have to stay lit until dawn. A dark flare before dawn is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
