# S3 ALLEYCOLU

You have the alley. The job is to stop the column on the road. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3alleycolu/

## Design

The column has to stop on the road. A truck that gets through is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
