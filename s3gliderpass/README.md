# S3 GLIDERPASS

In the glider, you clear the pass before the storm clock. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3gliderpass/

## Design

Clear the notch before the storm clock dies. Making the pass with the clock already gone fails it.

The browser build is one file. The link above is that file, not a capture of a desktop session.
