# S3 WHARFPURS

You have the wharf. The job is to be the last machine still running. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3wharfpurs/

## Design

Be the last machine still running. Stalling early ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
