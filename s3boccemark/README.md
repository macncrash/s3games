# S3 BOCCEMARK

Bocce: a finished mark ends it. That is the whole cartridge.

Play it in the browser: https://macncrash.github.io/s3games/play/s3boccemark/

## Design

Closest to the pallino finishes the mark. The rest of an end is not the job.
