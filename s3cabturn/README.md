# S3 CABTURN

Take the cab and make the three turns without tipping. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3cabturn/

## Design

Three turns upright, ahead of the other crew. Tipping fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
