# S3 HELI

Three pads. Land. Do not hover the clock out.

Play it in the browser: https://macncrash.github.io/s3games/play/s3heli/

## Design

Three pads, and hovering the clock out is a loss. Each landing has to be a landing, then you go to the next pad.

The browser build is one file. The link above is that file, not a capture of a desktop session.
