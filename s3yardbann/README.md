# S3 YARDBANN

One yard. Bring the banner back. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3yardbann/

## Design

The banner has to come back into the yard. Reaching it and staying outside is not done.

The browser build is one file. The link above is that file, not a capture of a desktop session.
