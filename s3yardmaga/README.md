# S3 YARDMAGA

At the yard, you make the magazine last longer than the raid. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3yardmaga/

## Design

The magazine has to outlast the raid. Emptying it before the raid ends fails the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
