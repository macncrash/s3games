# S3 FERRYTURN

In the ferry, you make the three turns without tipping. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3ferryturn/

## Design

Three turns without tipping. A list that puts the ferry over fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
