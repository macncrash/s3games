# S3 RAID

Ride the road into the yard and clear it.

Play it in the browser: https://macncrash.github.io/s3games/play/s3raid/

## Design

You ride in and the yard has to be empty. Leaving one standing is not a partial win. The road home is the proof.

The browser build is one file. The link above is that file, not a capture of a desktop session.
