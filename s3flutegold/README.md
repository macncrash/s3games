# S3 FLUTEGOLD

Flute: only the gold counts double. That is the whole cartridge.

Play it in the browser: https://macncrash.github.io/s3games/play/s3flutegold/

## Design

Only the gold counts double. Cream notes do not buy the line.

The browser build is one file. The link above is that file, not a capture of a desktop session.
