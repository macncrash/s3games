# S3 CULVERTCOLU

You have the culvert. The job is to stop the column on the road. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3culvertcolu/

## Design

Stop the column on the road. Letting a truck through is not done.

The browser build is one file. The link above is that file, not a capture of a desktop session.
