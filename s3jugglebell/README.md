# S3 JUGGLEBELL

A short juggle. You are done when the bell rings before the third try dies.

Play it in the browser: https://macncrash.github.io/s3games/play/s3jugglebell/

## Design

The bell rings only on a clean try, and it has to ring before the third try dies.

The browser build is one file. The link above is that file, not a capture of a desktop session.
