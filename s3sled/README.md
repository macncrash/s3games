# S3 SLED

One snow run. The clock is the other sled.

Play it in the browser: https://macncrash.github.io/s3games/play/s3sled/

## Design

The other sled is the clock. Beating a number on a board is not the race. Beating the sled next to you is.

The browser build is one file. The link above is that file, not a capture of a desktop session.
