# S3 RAIL

A cab, a line, stop boxes. A late arrival costs the run.

Play it in the browser: https://macncrash.github.io/s3games/play/s3rail/

## Design

The stop box is the station. Early and late both spoil the run, so the skill is arriving in the window, not beating the timetable by the most.

The browser build is one file. The link above is that file, not a capture of a desktop session.
