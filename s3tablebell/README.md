# S3 TABLEBELL

Table: the bell rings before the third try dies. That is the whole cartridge.

Play it in the browser: https://macncrash.github.io/s3games/play/s3tablebell/

## Design

Three tries at one table. The bell has to ring before the third try dies.

The browser build is one file. The link above is that file, not a capture of a desktop session.
