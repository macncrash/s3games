# S3 YARDPOUC

At the yard, you carry the pouch across. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3yardpouc/

## Design

The pouch has to cross the yard. Reaching the far side without it ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
