# S3 BIKEGRASS

In the bike, you land on the grass and come to a full stop. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3bikegrass/

## Design

Land on the grass and come to a full stop. Rolling past the grass fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
