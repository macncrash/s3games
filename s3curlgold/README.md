# S3 CURLGOLD

Curl: only the gold counts double. That is the whole cartridge.

Play it in the browser: https://macncrash.github.io/s3games/play/s3curlgold/

## Design

Only the gold counts double. Cream stones do not buy the double.

The browser build is one file. The link above is that file, not a capture of a desktop session.
