# S3 GIGABOY

Twelve porches. The marker has to sit on the mat.

Play it in the browser: https://macncrash.github.io/s3games/play/s3gigaboy/

## Design

The ring has to sit on the mat. A throw that misses the house is a lost order, and the shift ends if the stars fall under one. Twelve mats with the stars still up is the only pass.

The browser build is one file. The link above is that file, not a capture of a desktop session.
