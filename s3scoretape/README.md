# S3 SCORETAPE

A short score. You are done when the drawer has to match the tape.

Play it in the browser: https://macncrash.github.io/s3games/play/s3scoretape/

## Design

The drawer has to match the tape. A near match is still a miss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
