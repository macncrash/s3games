# S3 SPAN

Hold the span until the column is across.

Play it in the browser: https://macncrash.github.io/s3games/play/s3span/

## Design

The column has to cross. Holding the span after they are across is the win. Dying with them still on it is not.

The browser build is one file. The link above is that file, not a capture of a desktop session.
