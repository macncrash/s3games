# S3 KEELLANE

The keel has one job: stay in the lane for the whole leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3keellane/

## Design

Stay in the lane for the whole leg. Leaving the lane fails the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
