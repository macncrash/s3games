# S3 MOSAICMARK

A short mosaic. You are done when a finished mark ends it.

Play it in the browser: https://macncrash.github.io/s3games/play/s3mosaicmark/

## Design

A finished mark ends it. Stamps that never close the mark are still the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
