# S3 CAUSEWAYDAWN

One causeway. Keep the flares lit until dawn. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3causewaydawn/

## Design

Keep the flares lit until dawn. A dark causeway ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
