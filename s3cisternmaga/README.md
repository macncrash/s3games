# S3 CISTERNMAGA

At the cistern, you make the magazine last longer than the raid. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3cisternmaga/

## Design

The magazine has to outlast the raid. Empty before the last stop ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
