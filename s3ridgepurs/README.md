# S3 RIDGEPURS

You have the ridge. The job is to be the last machine still running. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3ridgepurs/

## Design

Be the last machine still running. Stopping the others and then dying yourself does not take the ridge.

The browser build is one file. The link above is that file, not a capture of a desktop session.
