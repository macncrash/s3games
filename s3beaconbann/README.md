# S3 BEACONBANN

At the beacon, you bring the banner back. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3beaconbann/

## Design

Bring the banner back to the beacon. Dropping it ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
