# S3 TUGBOATBOX

In the tugboat, you stop inside the box. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3tugboatbox/

## Design

Stop inside the box. Close to the box is still outside, and that fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
