# S3 GLIDERBOOM

The glider has one job: deliver the drive to the boom.

Play it in the browser: https://macncrash.github.io/s3games/play/s3gliderboom/

## Design

The drive has to land on the boom. Missing the boom fails the job even if you arrive.

The browser build is one file. The link above is that file, not a capture of a desktop session.
