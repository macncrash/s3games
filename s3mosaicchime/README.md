# S3 MOSAICCHIME

Play mosaic until the hour has to chime. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3mosaicchime/

## Design

The hour has to chime at 12:00:00. Tiles that miss the hour do not end it.

The browser build is one file. The link above is that file, not a capture of a desktop session.
