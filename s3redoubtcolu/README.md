# S3 REDOUBTCOLU

One redoubt. Stop the column on the road. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3redoubtcolu/

## Design

Stop the column on the road. A column still rolling is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
