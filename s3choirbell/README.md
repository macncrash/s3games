# S3 CHOIRBELL

A short choir. You are done when the bell rings before the third try dies.

Play it in the browser: https://macncrash.github.io/s3games/play/s3choirbell/

## Design

The bell has to ring before the third try dies. A late ring is still short.

The browser build is one file. The link above is that file, not a capture of a desktop session.
