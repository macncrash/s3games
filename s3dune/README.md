# S3 DUNE

One water stop. Don't boil the engine.

Play it in the browser: https://macncrash.github.io/s3games/play/s3dune/

## Design

One water stop, and the engine must not boil. Reaching camp with a cooked engine is not a pass.

The browser build is one file. The link above is that file, not a capture of a desktop session.
