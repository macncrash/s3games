# S3 BARGELOCK

The barge has one job: pass the lock without scraping a gate.

Play it in the browser: https://macncrash.github.io/s3games/play/s3bargelock/

## Design

Pass the lock without scraping a gate or a wall. A scrape fails the job even if you make it through.

The browser build is one file. The link above is that file, not a capture of a desktop session.
