# S3 RICKSHAWBOX

Take the rickshaw and stop inside the box. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3rickshawbox/

## Design

Stop inside the box ahead of the other crew. Outside the box fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
