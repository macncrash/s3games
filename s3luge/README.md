# S3 LUGE

One ice chute. Stay off the walls.

Play it in the browser: https://macncrash.github.io/s3games/play/s3luge/

## Design

One ice chute. Touching the wall ends the run. The clock is useless if you are in the wall.

The browser build is one file. The link above is that file, not a capture of a desktop session.
