# S3 SALLYCLER

You have the sally. The job is to clear the ground before the clock dies. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3sallycler/

## Design

Clear the ground before the clock dies. A late clear is not done.

The browser build is one file. The link above is that file, not a capture of a desktop session.
