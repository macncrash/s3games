# S3 ALLEYPOUC

At the alley, you carry the pouch across. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3alleypouc/

## Design

The pouch has to cross the alley. Reaching the far side without it ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
