# S3 CISTERNDOOR

One cistern. Hold the door for three minutes. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3cisterndoor/

## Design

Hold the door for three minutes. Breaking the seal early is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
