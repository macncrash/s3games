# S3 MILL CLER

At the mill, you clear the ground before the clock dies. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3millcler/

## Design

Rake every pile into the mill door before the clock dies. A clean yard after the clock is already over.

The browser build is one file. The link above is that file, not a capture of a desktop session.
