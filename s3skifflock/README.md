# S3 SKIFFLOCK

The skiff has one job: pass the lock without scraping a gate.

Play it in the browser: https://macncrash.github.io/s3games/play/s3skifflock/

## Design

One lock. A scrape on a gate fails the pass even if the skiff made it through.

The browser build is one file. The link above is that file, not a capture of a desktop session.
