# S3 PLOWLOCK

In the plow, you pass the lock without scraping a gate. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3plowlock/

## Design

Pass the lock without scraping a gate. A scrape spends the run even if you clear the lock.

The browser build is one file. The link above is that file, not a capture of a desktop session.
