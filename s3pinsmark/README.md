# S3 PINSMARK

Play pins until a finished mark ends it. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3pinsmark/

## Design

A strike or a spare opens a mark, and that finished mark ends it. Bowling out the rest of the card is not the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
