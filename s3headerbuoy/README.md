# S3 HEADERBUOY

Take the header and round the buoys and return to the same dock. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3headerbuoy/

## Design

Round the buoys and return ahead of the other crew. A circuit that finishes late fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
