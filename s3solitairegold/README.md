# S3 SOLITAIREGOLD

A short solitaire. You are done when only the gold counts double.

Play it in the browser: https://macncrash.github.io/s3games/play/s3solitairegold/

## Design

Only the gold counts double. Cream cards do not buy the line.

The browser build is one file. The link above is that file, not a capture of a desktop session.
