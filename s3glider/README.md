# S3 GLIDER

Ridge lift. Land in the field, not the trees.

Play it in the browser: https://macncrash.github.io/s3games/play/s3glider/

## Design

Ridge lift gets you there. The field is the win and the trees are the fail. A long flight that lands in the trees is a crash.

The browser build is one file. The link above is that file, not a capture of a desktop session.
