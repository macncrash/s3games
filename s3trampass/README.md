# S3 TRAMPASS

Take the tram and clear the pass before the storm clock. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3trampass/

## Design

Clear the pass before the storm clock. The other crew is that clock, and a late crest fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
