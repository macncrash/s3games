# S3 SPANPOUC

You have the span. The job is to carry the pouch across. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3spanpouc/

## Design

The pouch has to cross the span. Reaching the far side without it is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
