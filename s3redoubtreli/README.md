# S3 REDOUBTRELI

You have the redoubt. The job is to hold until the relief bell. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3redoubtreli/

## Design

Hold until the relief bell. Leaving early ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
