# S3 TOWERLADD

You have the tower. The job is to reach the far ladder. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3towerladd/

## Design

Reach the far ladder. Stopping short of it ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
