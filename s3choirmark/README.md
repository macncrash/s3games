# S3 CHOIRMARK

A short choir. You are done when a finished mark ends it.

Play it in the browser: https://macncrash.github.io/s3games/play/s3choirmark/

## Design

Three on the bar ends the mark. A spread that is still open is not finished.

The browser build is one file. The link above is that file, not a capture of a desktop session.
