# S3 PLOWKILO

The plow has one job: finish the kilometer without touching wheels.

Play it in the browser: https://macncrash.github.io/s3games/play/s3plowkilo/

## Design

Finish the kilometer without touching a wheel. A scrape spends the run even if you make the distance.

The browser build is one file. The link above is that file, not a capture of a desktop session.
