# S3 SKIFFKILO

Take the skiff and finish the kilometer without touching wheels. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3skiffkilo/

## Design

Finish the kilometer with the wheels untouched and time left on the other crew's clock. A scrape spends the run even if you make the distance.

The browser build is one file. The link above is that file, not a capture of a desktop session.
