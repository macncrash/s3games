# S3 EIGHTSEVEN

Play eight until first to seven. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3eightseven/

## Design

First to seven balls, then leave. A six that looks close is still short. The 8 stays on the spot.

The browser build is one file. The link above is that file, not a capture of a desktop session.
