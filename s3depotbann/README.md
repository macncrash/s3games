# S3 DEPOTBANN

You have the depot. The job is to bring the banner back. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3depotbann/

## Design

The banner has to come back to the depot. Reaching it and staying away is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
