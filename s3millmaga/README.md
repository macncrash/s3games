# S3 MILLMAGA

You have the mill. The job is to make the magazine last longer than the raid. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3millmaga/

## Design

The magazine has to outlast the raid. Burning the rounds and dying with the raid still up is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
