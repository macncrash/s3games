# S3 LANTERN

Light the lamps in order. A miss hands one back to the dark.

Play it in the browser: https://macncrash.github.io/s3games/play/s3lantern/

## Design

Light the lamps in order. A miss hands one back to the dark, so skipping ahead undoes the chain.

The browser build is one file. The link above is that file, not a capture of a desktop session.
