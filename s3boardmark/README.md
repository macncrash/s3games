# S3 BOARDMARK

Play board until a finished mark ends it. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3boardmark/

## Design

Hold the mark and leave the desk. A mark that slips before you leave is still open.

The browser build is one file. The link above is that file, not a capture of a desktop session.
