# S3 GATEPURS

At the gate, you be the last machine still running. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3gatepurs/

## Design

Be the last machine still running. Stopping the others and then dying yourself does not take the purse.

The browser build is one file. The link above is that file, not a capture of a desktop session.
