# S3 BUSLOCK

Take the bus and pass the lock without scraping a gate. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3buslock/

## Design

Pass the lock without scraping a gate. One scrape fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
