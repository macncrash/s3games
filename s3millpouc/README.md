# S3 MILLPOUC

You have the mill. The job is to carry the pouch across. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3millpouc/

## Design

The pouch has to cross the mill. Stopping in the middle is not across.

The browser build is one file. The link above is that file, not a capture of a desktop session.
