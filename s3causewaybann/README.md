# S3 CAUSEWAYBANN

At the causeway, you bring the banner back. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3causewaybann/

## Design

Bring the banner back to the causeway. Reaching the banner and leaving it there is not done.

The browser build is one file. The link above is that file, not a capture of a desktop session.
