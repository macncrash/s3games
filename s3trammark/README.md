# S3 TRAMMARK

In the tram, you set down on the mark. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3trammark/

## Design

Set the tram down on the mark. Close to the mark is still a missed leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
