# S3 BREACH

The hall, then the banner. Bring it back.

Play it in the browser: https://macncrash.github.io/s3games/play/s3breach/

## Design

The banner has to come back through the door you broke. Reaching it and dying in the hall is not a rescue.

The browser build is one file. The link above is that file, not a capture of a desktop session.
