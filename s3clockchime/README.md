# S3 CLOCKCHIME

Play clock until the hour has to chime. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3clockchime/

## Design

The hour has to chime at 12:00:00. Leaving before the chime is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
