# S3 YARD

Junkyard. Last machine still running takes the purse.

Play it in the browser: https://macncrash.github.io/s3games/play/s3yard/

## Design

Last machine running takes the purse. You are not scored on style. You are scored on being the one still moving.

The browser build is one file. The link above is that file, not a capture of a desktop session.
