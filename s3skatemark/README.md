# S3 SKATEMARK

Play skate until a finished mark ends it. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3skatemark/

## Design

Land the three spots with no falls. A fall ends the mark even if the line looks finished.

The browser build is one file. The link above is that file, not a capture of a desktop session.
