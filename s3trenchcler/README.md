# S3 TRENCHCLER

One trench. Clear the ground before the clock dies. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3trenchcler/

## Design

Clear the ground before the clock dies. Anything left is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
