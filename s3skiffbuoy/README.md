# S3 SKIFFBUOY

In the skiff, you round the buoys and return to the same dock. Missing the end fails the leg.

Play it in the browser: https://macncrash.github.io/s3games/play/s3skiffbuoy/

## Design

Round the buoys and take the same dock you left. A fast lap that finishes at the wrong end fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
