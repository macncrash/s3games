# S3 SHUFFLEMARK

Play shuffle until a finished mark ends it. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3shufflemark/

## Design

The disk has to stop inside the painted mark. Close to the mark is still out.

The browser build is one file. The link above is that file, not a capture of a desktop session.
