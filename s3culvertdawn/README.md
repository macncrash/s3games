# S3 CULVERTDAWN

You have the culvert. The job is to keep the flares lit until dawn. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3culvertdawn/

## Design

Keep the flares lit until dawn. A dark flare is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
