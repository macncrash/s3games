# S3 SPANBANN

At the span, you bring the banner back. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3spanbann/

## Design

The banner has to come back onto the span. Reaching it and staying off the span ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
