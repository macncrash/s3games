# S3 CURLTAPE

A short curl. You are done when the drawer has to match the tape.

Play it in the browser: https://macncrash.github.io/s3games/play/s3curltape/

## Design

The drawer has to match the tape, then you leave. A till that is close is still open.

The browser build is one file. The link above is that file, not a capture of a desktop session.
