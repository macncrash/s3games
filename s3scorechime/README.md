# S3 SCORECHIME

Score: the hour has to chime. That is the whole cartridge.

Play it in the browser: https://macncrash.github.io/s3games/play/s3scorechime/

## Design

The hour has to chime. Leaving before the chime is a loss.

The browser build is one file. The link above is that file, not a capture of a desktop session.
