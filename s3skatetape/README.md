# S3 SKATETAPE

A short skate. You are done when the drawer has to match the tape.

Play it in the browser: https://macncrash.github.io/s3games/play/s3skatetape/

## Design

The drawer has to match the tape. A pop that pays the same and is not on the tape stays out.

The browser build is one file. The link above is that file, not a capture of a desktop session.
