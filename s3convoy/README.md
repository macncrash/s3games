# S3 CONVOY

The truck has to arrive. Lose it and the road ends.

Play it in the browser: https://macncrash.github.io/s3games/play/s3convoy/

## Design

The truck arriving is the win. Your own hull is only the means. A hero who loses the truck has lost.

The browser build is one file. The link above is that file, not a capture of a desktop session.
