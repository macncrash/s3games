# S3 BUSGRASS

The bus has one job: land on the grass and come to a full stop.

Play it in the browser: https://macncrash.github.io/s3games/play/s3busgrass/

## Design

Land on the grass and come to a full stop. Rolling past the grass fails the job.

The browser build is one file. The link above is that file, not a capture of a desktop session.
