# S3 SHELVEBELL

Play shelve until the bell rings before the third try dies. Leave when that is true.

Play it in the browser: https://macncrash.github.io/s3games/play/s3shelvebell/

## Design

The bell rings only on a clean try, and it has to ring before the third try dies.

The browser build is one file. The link above is that file, not a capture of a desktop session.
