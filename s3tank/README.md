# S3 TANK

One street, two tanks. The one still moving takes the block.

Play it in the browser: https://macncrash.github.io/s3games/play/s3tank/

## Design

One street, two machines. The block is won by whoever is still moving, so armor is a clock and not a health bar you hide behind.

The browser build is one file. The link above is that file, not a capture of a desktop session.
