# S3 PALISADEPURS

One palisade. Be the last machine still running. Then it is done.

Play it in the browser: https://macncrash.github.io/s3games/play/s3palisadepurs/

## Design

Be the last machine still running. Stalling early ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
