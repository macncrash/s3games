# S3 SPANMAGA

You have the span. The job is to make the magazine last longer than the raid. Anything else is a loss.

Play it in the browser: https://macncrash.github.io/s3games/play/s3spanmaga/

## Design

The magazine has to outlast the raid on the open deck. Emptying it before the raid ends fails the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
