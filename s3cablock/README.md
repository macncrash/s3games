# S3 CABLOCK

Take the cab and pass the lock without scraping a gate. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3cablock/

## Design

Pass the lock clear of both gates. A scrape fails the run even if you made it through.

The browser build is one file. The link above is that file, not a capture of a desktop session.
