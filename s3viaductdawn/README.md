# S3 VIADUCTDAWN

At the viaduct, you keep the flares lit until dawn. Miss that and the watch is over.

Play it in the browser: https://macncrash.github.io/s3games/play/s3viaductdawn/

## Design

Keep the flares lit until dawn. A dark viaduct ends the watch.

The browser build is one file. The link above is that file, not a capture of a desktop session.
