# S3 EIGHTGOLD

A short eight. You are done when only the gold counts double.

Play it in the browser: https://macncrash.github.io/s3games/play/s3eightgold/

## Design

The 8 in the top right finishes it, and only the gold counts double. Cream balls do not buy the double.

The browser build is one file. The link above is that file, not a capture of a desktop session.
