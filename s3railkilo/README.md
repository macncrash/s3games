# S3 RAILKILO

Take the rail and finish the kilometer without touching wheels. The clock is the other crew.

Play it in the browser: https://macncrash.github.io/s3games/play/s3railkilo/

## Design

Finish the kilometer without touching wheels. One touch fails the leg.

The browser build is one file. The link above is that file, not a capture of a desktop session.
